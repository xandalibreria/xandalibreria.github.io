¿Qué formato conviene?

Una referencia rápida antes de elegir el destino.

PNG

Sin pérdida de calidad y con transparencia real. Ideal para logotipos, íconos y capturas con texto nítido.

Mejor para gráficos y transparencias

JPG

Compresión con pérdida muy eficiente para fotografías. No admite transparencia.

Mejor para fotos y fondos

WEBP

Calidad similar al JPG con archivos hasta 30% más ligeros, y admite transparencia.

Mejor para uso web general

AVIF

El más compacto disponible hoy, aunque el soporte del navegador aún es variable.

Mejor para máximo ahorro
